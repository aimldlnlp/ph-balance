# PH-Balance Project Specification

## Title

PH-Balance: Port-Hamiltonian Control for a Self-Balancing Robot

## Vision

Build a research-inspired robotics simulation packaged as a professional
engineering portfolio.

The project investigates energy-based control for an unstable inverted
pendulum robot.

## Research Question

Can a Port-Hamiltonian controller improve stability, disturbance
rejection, and robustness compared with conventional PID control?

## Constraints

-   Python only
-   CPU only
-   No deep learning
-   No hardware dependency
-   Reproducible experiments

## Main Controllers

1.  PID baseline
2.  Port-Hamiltonian energy-based controller

## Deliverables

-   Clean Python architecture
-   Simulation animation
-   Comparison plots
-   Demo video
-   Modern README showcase
