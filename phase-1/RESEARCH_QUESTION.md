# Research Question

## Main Question

Can Port-Hamiltonian control provide robust stabilization for a
self-balancing robot under disturbances and model uncertainty?

## Hypothesis

H1: Port-Hamiltonian control can stabilize the robot from unstable
initial conditions.

H2: Port-Hamiltonian control provides better disturbance rejection.

H3: Energy-based control can reduce unnecessary control effort.
