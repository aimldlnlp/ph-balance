# Visualization Style

## Goal

Create engineering portfolio quality visuals.

## Fonts

Primary: Latin Modern Sans (`lmsans10` bundled in `assets/fonts/`)

Alternatives: - Latin Modern Roman - Inter - IBM Plex Sans - Helvetica Neue - Manrope

The bundled font is registered directly with Matplotlib, so rendering does not
depend on a system-wide font installation.

## Figures

Required:

1.  Robot animation
2.  Angle response
3.  Energy evolution
4.  Controller comparison

## Design

Prefer: - minimal layout - clear labels - readable typography -
presentation-ready plots
