# PH-Balance Phase 2C Master Plan

## Objective

Validate PH-V3 experimentally. Phase 2B showed PH-V3 improves local
stability, but robustness is not yet proven.

## Scope

Do not create a new controller.

Focus on: - PH-V3 audit - experiment integration - gain tuning - metric
correction - final comparison

Keep: - PID - PH-V1 - PH-V2 - PH-V3

## Success Criteria

-   PH-V3 integrated into official experiments
-   metrics scientifically correct
-   gains systematically selected
-   robustness evaluated
-   reproducible final comparison
