# Task 03: Validation

## Objective

Validate PH-V2 before large experiments.

## Required Checks

### Physics

Verify:

-   equilibrium behavior
-   correct torque direction

### Controller

Compare:

PID PH-V1 PH-V2

Do not claim improvement without numerical evidence.

Record:
